# FAQ-Chatbot-Using-Python
An AI-powered FAQ Chatbot developed using Python, NLP, TF-IDF Vectorization, and Cosine Similarity. This chatbot matches user questions with predefined FAQs and provides intelligent responses interactively

CodeAlpha AI Internship - Task 2

This project is a simple FAQ Chatbot developed using Python and Natural Language Processing (NLP) techniques. The chatbot matches user questions with predefined FAQs and provides the most relevant response using cosine similarity.

Features

✅ NLP Text Preprocessing✅ Tokenization & Stopword Removal✅ TF-IDF Vectorization✅ Cosine Similarity Matching✅ Interactive Chatbot Response System

Technologies Used

Python

NLTK

Scikit-learn

Sample Output

You: what is aiChatbot: AI means Artificial Intelligence.

You: what is pythonChatbot: Python is a programming language.

Project Workflow

User Question → Text Preprocessing → TF-IDF Vectorization → Cosine Similarity → Best Matching Answer
